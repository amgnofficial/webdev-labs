# Assignment 1: Front-End

**Objective:** This assignment is designed to build your proficiency in modern JavaScript and CSS layout techniques. You will work through practical, real-world examples and create a reference guide for the two most important CSS layout systems: Flexbox and Grid.

**Timeline:** The assignment runs for 5 weeks, from **September 28th to October 31st**.

**Core Requirements:** You are required to complete **one (1) submission per week** for the duration of the assignment. Each submission must be committed and pushed to your personal GitHub repository.

**Instructions:**

1.  **Create an Account:** Go to [https://courses.wesbos.com/](https://courses.wesbos.com/) and create a new account.
2.  **Select Your Videos:** Browse the course library and choose **five (5) videos** that interest you. They can be from any course on the platform.
3.  **Follow Along and Build:** Watch each video and code along with the instructor. The goal is to understand the concepts and build the project demonstrated in the video.
4.  **Submit Your Work:**
    - Create a new repository on GitHub specifically for this assignment (e.g., `javascript-360-assignment`).
    - For each video you complete, create a separate folder in the repository (e.g., `01-video-name`, `02-video-name`).
    - Place all the code for that project in its corresponding folder. Include a `README.md` file in each folder explaining what the project is and what you learned.
    - You must make **one commit and push per week** for five weeks. Each submission should correspond to one completed video project.

### Submission and Grading

- **Repository:** All your work for both parts must be in a single GitHub repository.
- **Weekly Commits:** You must have at least one meaningful commit per week for five weeks.
- **Final Submission:** After the 5-week period from September 28th, the final state of the repository will be graded.
